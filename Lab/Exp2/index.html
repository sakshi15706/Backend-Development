1. Types of CSS

Inline CSS: this paragraph is styled using the style attribute on the tag itself.

Internal CSS: this paragraph is styled by the <style> block inside the <head>.

External CSS: the rest of the page (header, navigation, sections, cards) is styled by style.css, linked with <link rel="stylesheet">.

Priority order: Inline CSS > ID selector > Class selector > Element selector. With equal specificity, the rule written last wins.
