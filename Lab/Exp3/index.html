About Responsive Design

What is it?

Responsive web design makes a page look good on all devices by changing the layout according to the screen width. It uses a flexible grid, flexible images and media queries.

Why is it needed?

People browse on phones, tablets, laptops and large monitors. A single responsive page works on all of them, so there is no need for a separate mobile website.
