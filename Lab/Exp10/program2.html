    What is jQuery?

    jQuery is a fast, small JavaScript library. It makes DOM selection, events, effects and AJAX much shorter to write.

    What does $ mean?

    $ is a short name for the jQuery function. $("p") selects all paragraphs.

    Why use $(document).ready()?

    It runs the code only after the HTML is fully loaded, so the elements exist when jQuery looks for them.
